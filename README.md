# KK Fashion — Final Website

A multi-page static fashion storefront.

## Pages

- `index.html` — Landing page
- `home.html` — Home / new collection
- `products.html` — Product listing
- `product.html` — Product detail
- `categories.html` — Categories
- `orders.html` — Orders
- `profile.html` — Profile

## Shared files

- `css/style.css` — Shared styling and responsive design
- `js/products.js` — Product data and product helpers
- `js/script.js` — Shared cart, wishlist and UI logic
- `js/navigation.js` — Navigation helpers
- `assets/icons/favicon.svg` — Favicon

## Design

The site uses a restrained premium fashion palette built around ink, ivory, olive, stone and brick. The landing page is intentionally separate from the shopping home page so visitors first see a polished brand introduction.

## Important UX details

- Landing page has clear high-contrast CTAs.
- `Discover Collection` leads to the shopping home.
- `Explore Collection` leads directly to products.
- Home has a prominent new-season offer and `Start Shopping` CTA.
- Product page does not show color or quantity selectors.
- Product reviews use editorial-style cards rather than chat/message bubbles.
- Bottom navigation remains fixed at the bottom on supported pages.
